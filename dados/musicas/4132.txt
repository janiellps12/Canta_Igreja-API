**Para tudo há um tempo,
para cada coisa há um momento,
debaixo do céu.**

1. Tempo para nascer, tempo para morrer,
   tempo para plantar, tempo para arrancar.
   Tempo para ferir, tempo para sarar,
   tempo para demolir e construir.

2. Tempo para chorar, tempo para sorrir,
   tempo para gemer e tempo pra dançar.
   Tempo para calar, tempo para falar,
   tempo para amar, tempo pra guerra
   e tempo pra paz.
